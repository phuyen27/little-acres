
# Little Acres 🌱

A cozy pixel-art farming game.

## About

Little Acres is a small farming game where players can grow crops, raise animals, collect products and build their own little farm.

## Features

- Plant and harvest different crops
- Raise farm animals
- Collect eggs, milk, wool and other products
- Sell products to earn coins
- Unlock new farmland
- Dynamic day and night cycle
- Random weather and rain
- Save and restore game progress
- Pixel-art graphics

## How to Play

1. Open `index.html` in a web browser.
2. Use the hoe to prepare the soil.
3. Select seeds and plant crops.
4. Water crops and wait for them to grow.
5. Harvest crops and sell your products.
6. Buy animals and collect their products.
7. Expand your farm.

## Technologies

- HTML5
- CSS3
- JavaScript
- HTML Canvas
- LocalStorage

## Save Data

Game progress is automatically saved in the browser using LocalStorage.
